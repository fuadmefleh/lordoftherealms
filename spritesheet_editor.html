Image models return opaque pictures that sit off any grid. With the pixel grid on, the guide is the sheet at its real size in game pixels, magnified, so the model draws each pixel at tile size and clean-up reads them back one per block instead of shrinking a big painting. Clean-up removes the background, then puts what was drawn on the grid: props and structures are found one by one and laid out a whole number of tiles each; tile sheets are cut out of the layout guide's grid, dropping any gutters or grid lines the model drew.
